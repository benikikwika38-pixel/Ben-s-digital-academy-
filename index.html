📘 Apprendre le langage C

Cours complet du niveau débutant avec explications détaillées

Chapitre 1 : Introduction

Le langage C est un langage de programmation utilisé pour créer des logiciels.
Il permet de donner des instructions précises à l’ordinateur.
Un programme C commence toujours par une fonction appelée main.
C’est le point d’entrée du programme.La structure de base est : #include  int main(){ return 0; }

La ligne #include permet d’utiliser des fonctions comme printf. printf sert à afficher du texte à l’écran. Chaque instruction se termine par un point-virgule ; Les accolades { } définissent un bloc de code. Le programme s’exécute de haut en bas. Le return 0 indique que le programme s’est bien terminé.

Le C est un langage sensible à la casse. printf est différent de Printf.

C’est un langage puissant utilisé pour créer des systèmes.

Chapitre 2 : Entrées / Sorties

printf permet d’afficher des informations.
scanf permet de lire les données entrées par l’utilisateur.Exemple : int age; printf("Entre ton age : "); scanf("%d", &age);

%d est utilisé pour les entiers. %f pour les nombres décimaux. %c pour les caractères.

Le symbole & permet de récupérer l’adresse mémoire.

scanf attend une entrée utilisateur.

Il faut respecter les formats sinon erreur.

On peut afficher la valeur ensuite avec printf.

Les entrées/sorties sont essentielles pour interagir.

Chapitre 3 : Variables

Une variable sert à stocker une valeur.
On doit déclarer une variable avant de l’utiliser.Types principaux : int : entier float : nombre décimal char : caractère

Exemple : int a = 10; float b = 5.5; char c = 'A';

Chaque variable a un type spécifique. On peut modifier la valeur.

Les variables sont stockées en mémoire.

Il faut donner un nom clair à chaque variable.

On peut afficher une variable avec printf.

Les variables sont la base de la programmation.
